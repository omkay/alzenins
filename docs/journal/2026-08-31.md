# Journal — 2026-08-31

**Phase:** Phase 1 awaiting sign-off · Phase 2 spike · **Participants:** Omar (owner), Claude

## What we did

- Propagated the Qatar/MamoPay currency correction into the **Price Book artifact**, which
  was still the one place carrying the wrong assumption. The 2026-08-30 spike proved the
  MamoPay sandbox rejects QAR, but the artifact's `MARKETS` table still had Qatar charging
  in `QAR`, and its footer still said eight markets need a fallback.
  - `QA` charge currency `QAR` → `AED`.
  - Footer now says **nine** markets, names the date the change happened, and lists the
    twelve currencies the sandbox actually accepts (AED, AUD, CAD, CHF, DZD, EGP, EUR,
    GBP, RON, SAR, TRY, USD) so a reader does not have to trust the count alone.
  - Everything else — the saved price data, the FX rates, the layout — was carried over
    byte-for-byte from the owner's saved version. Nothing the owner entered was touched.
- Artifact: <https://claude.ai/code/artifact/93ab9dbe-e4e7-44a9-9c00-beb35c9ff80f>

## Decisions taken

- No new ADR. This is not a new decision — it is ADR-0003 Option A applied to one market
  that the spike moved from the "covered" column to the "fallback" column. ADR-0003 itself
  was already corrected on 2026-08-30.

## Learned

- The Qatar correction had **four** homes, not two: `code/src/lib/markets.ts`,
  `docs/data-model.md`, `docs/decisions/ADR-0003-*.md`, and the price-book artifact. The
  artifact is outside the repo, so no grep over the working tree would have found it. When
  a fact this load-bearing changes, the artifacts have to be swept by hand.
- The price book's CSV export writes a `charge_currency` column straight from that
  `MARKETS` table. Had it been exported before this fix, every Qatar row would have carried
  `QAR` into whatever consumed it. The fix landed before any export was taken.

## Open / blocked

- **Still the gating question:** is the twelve-currency list a sandbox restriction or the
  production reality? Only Mamo can answer, in writing. It blocks authoring the real price
  books, because it decides whether Qatar (and eight others) ever get their own currency.
- The price book now has a number in all sixteen markets for all four SKUs — but only
  **UAE 390 AED** and **Saudi 399 SAR** are the owner's own figures. The other fourteen are
  the starting points suggested on 2026-08-27, now persisted. They still need a real pass
  before they become price books.
- Phase 1 sign-off walkthrough (`docs/phases/phase-1-signoff.md`) — seven manual steps,
  unperformed. Resend domain verification still limits staging sign-in to one address.
